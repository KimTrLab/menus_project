종합예제: 메뉴 CRUD

이 예제에서 연습하는 것
- controlled input과 폼 제출로 메뉴를 등록하고 수정한다.
- 메뉴 배열은 map()으로 목록을 만들고, key에는 메뉴 id를 사용한다.
- 메뉴 수정은 map()으로 새 배열을 만들고, 삭제는 filter()로 새 배열을 만든다.
- 즐겨찾기 변경은 대상 메뉴 객체를 복사해 새 값으로 바꾼다.
- MenuList와 MenuItem은 props와 callback props로 부모와 연결된다.
- 메뉴가 없을 때는 조건부 렌더링으로 안내 문구를 보여 준다.

코드 읽는 순서
1. MenuItem에서 메뉴 하나와 버튼을 확인한다.
2. MenuList에서 메뉴 배열을 반복하고 각 MenuItem에 props를 전달한다.
3. 페이지 컴포넌트에서 state와 추가·수정·즐겨찾기·삭제 함수를 확인한다.
4. 버튼을 눌러 state가 바뀌고 목록이 다시 렌더링되는 것을 확인한다.

초보자 팁
- 한 번에 모든 함수를 외우기보다 메뉴 추가부터 실행해 본다.
- 다음으로 수정, 즐겨찾기, 삭제를 한 가지씩 시험한다.
- 메뉴 이름을 비운 채 제출해 입력 오류 안내를 확인한다.
