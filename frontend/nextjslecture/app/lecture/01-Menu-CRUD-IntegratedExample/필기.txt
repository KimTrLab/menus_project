종합예제: 메뉴 관리와 CRUD

핵심 개념
- CRUD는 데이터 생성(Create), 조회(Read), 수정(Update), 삭제(Delete)의 기본 작업을 뜻한다.
- 메뉴 배열은 현재 메뉴 데이터의 단일 기준이다. 메뉴를 바꾸면 새 배열을 state로 저장한다.
- 화면은 그 state를 바탕으로 계산되므로 메뉴 데이터와 목록 UI가 함께 갱신된다.

컴포넌트와 데이터 흐름
1. 페이지 컴포넌트가 메뉴 배열과 편집 중인 메뉴 ID를 소유한다.
2. MenuList는 메뉴 배열을 순회하고, 각 항목을 MenuItem으로 전달한다.
3. 메뉴와 함수는 props로 자식에게 내려간다.
4. 버튼을 누르면 자식이 callback prop을 호출해 부모에게 수정·삭제·즐겨찾기 변경을 요청한다.
5. 부모가 state를 새 배열로 갱신하면 React가 목록을 다시 렌더링한다.

데이터가 바뀌는 원리
- 등록은 기존 배열에 새 메뉴 객체를 붙인 새 배열을 만든다.
- 수정과 즐겨찾기 전환은 map()으로 대상 객체만 복사해 새 배열을 만든다.
- 삭제는 filter()로 대상 id를 제외한 새 배열을 만든다.
- id는 항목의 정체성을 유지하는 식별자다. 배열 순서가 달라져도 같은 메뉴를 찾을 수 있다.

조건부 화면
- 메뉴 배열이 비어 있으면 안내 문구를 보여 주고, 데이터가 있으면 목록을 보여 준다.
- 수정 중에는 버튼 문구와 취소 버튼이 달라진다.
- 입력값이 공백뿐이면 등록하지 않고 오류 상태를 표시한다.

초보자용 진행 순서
1. 초기 메뉴 목록과 MenuItem 화면을 확인한다.
2. 메뉴 하나를 추가하고 목록 수가 바뀌는지 본다.
3. 수정, 즐겨찾기 전환, 삭제를 하나씩 시험한다.
4. 마지막 메뉴를 삭제해 빈 상태 화면을 확인한다.
5. 각 동작에서 부모 state와 자식 callback의 역할을 설명해 본다.
