강의 필기: 컴포넌트 합성과 children

핵심 개념
- 큰 화면은 여러 작은 컴포넌트를 결합해 만든다. 이를 컴포넌트 합성이라고 한다.
- 재사용 컴포넌트는 자기 역할에 해당하는 구조를 제공하고, 안쪽 내용은 사용하는 쪽에서 전달할 수 있다.
- 여는 태그와 닫는 태그 사이에 작성한 JSX는 자식 컴포넌트의 children prop으로 전달된다.

MenuPanel의 화면 조립 방식
1. MenuPanel은 바깥쪽 section과 제목을 만든다.
2. title prop으로 패널 제목을 받고 children으로 안쪽 내용을 받는다.
3. 사용하는 쪽은 MenuPanel 태그 사이에 메뉴 카드나 목록을 작성한다.
4. 같은 MenuPanel 구조에 서로 다른 children을 넣어 추천 메뉴와 최근 메뉴 화면을 만든다.

데이터 배열로 패널을 반복할 때
- panels 배열의 각 객체가 패널 하나의 제목과 메뉴 데이터를 가진다.
- 바깥 map()은 MenuPanel을 여러 개 만들고, 안쪽 map()은 각 패널의 메뉴 목록을 만든다.
- 부모가 화면 트리를 조립하고, MenuPanel은 전달받은 children을 정해진 위치에 보여 준다.

컴포넌트 합성의 의미
- children은 특별한 데이터 저장소가 아니라 컴포넌트에 전달되는 props 중 하나다.
- 공통 레이아웃과 달라지는 내용을 분리하면 UI 구조를 재사용하기 쉽다.
- Next.js layout도 children을 받아 공통 레이아웃 안에 현재 페이지 내용을 배치한다.
