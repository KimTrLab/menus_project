강의 필기: 메뉴 배열 state의 불변 업데이트

핵심 내용
- React state의 배열이나 객체를 직접 수정(push, splice, 속성 대입 등)하지 않는다.
- 새 배열이나 새 객체를 만들어 setter에 전달하면 React가 변경을 올바르게 감지하고 렌더링할 수 있다.
- 이전 state를 바탕으로 새 state를 계산할 때는 setter의 함수형 형태를 사용한다.

예제에서 사용한 배열 메서드
- 추가: [...currentMenus, newMenu]로 기존 요소와 새 메뉴를 담은 새 배열을 만든다.
- 수정: map()으로 배열을 만들고 대상 메뉴만 {...menu, isFavorite: ...}으로 복사한다.
- 삭제: filter()로 대상 메뉴를 제외한 새 배열을 만든다.

함수형 업데이트
- setMenus(currentMenus => ...)는 React가 실제로 적용할 최신 state를 인수로 받는다.
- 빠르게 연속으로 발생하는 업데이트에서도 이전 렌더의 오래된 값을 사용하는 문제를 줄인다.

실제 앱과 연결
- 메뉴 등록, 즐겨찾기 변경, 삭제에 배열의 추가·수정·삭제 패턴을 적용한다.
- 자식 컴포넌트에서 부모 state를 갱신하는 흐름은 Callback Props 강의에서 이어서 다룬다.
