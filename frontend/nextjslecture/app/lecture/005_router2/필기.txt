강의 필기: 상품 상세 페이지와 동적 라우팅

실습 목표
- 여러 상품이 같은 상세 화면 구조를 사용하도록 동적 경로를 만든다.
- 상품마다 page.js를 따로 만들지 않고 URL의 상품 ID로 표시할 데이터를 선택한다.

파일과 URL의 관계
- app/lecture/005_router2/page.js는 /lecture/005_router2 상품 목록 페이지다.
- app/lecture/005_router2/products/[productId]/page.js는 상품 상세 페이지다.
- [productId]는 동적 경로 세그먼트다. 예를 들어 /lecture/005_router2/products/keyboard로 접속하면 productId는 "keyboard"다.

데이터와 화면 흐름
1. productData.js에 상품 ID, 이름, 가격, 설명을 배열로 저장한다.
2. 목록 페이지는 products 배열을 map()으로 순회해 상품별 상세 링크를 만든다.
3. 상세 페이지는 await params로 productId를 가져온다. Next.js 16의 page params는 Promise다.
4. find()로 ID가 일치하는 상품을 찾고, 이름·설명·가격을 화면에 표시한다.
5. ID에 해당하는 상품이 없으면 notFound()로 404 페이지를 표시한다.

동적 라우팅이 유리한 이유
- 상품이 많아져도 상품별 page.js를 만들 필요 없이 공통 상세 페이지를 재사용한다.
- 새 상품을 추가할 때는 데이터만 추가하면 같은 화면 형식으로 상세 페이지가 제공된다.
- 상품 ID가 URL에 포함되어 각 상품의 주소를 공유하거나 북마크하기 쉽다.

실제 서비스에서 고려할 점
- 예제 데이터는 파일에 있지만, 실제 상품 정보는 API나 데이터베이스에서 조회할 수 있다.
- 동적 경로를 사용하더라도 존재하지 않는 ID, 권한, 데이터 로딩 상태 등을 처리해야 한다.
