강의 필기: Callback Props와 state 끌어올리기

핵심 내용
- props는 부모에서 자식 방향으로 전달된다.
- 자식이 부모의 데이터를 바꾸어야 할 때는 부모가 변경 함수를 만들어 callback prop으로 전달한다.
- state를 여러 컴포넌트가 공유해야 하면 가장 가까운 공통 부모가 state를 소유한다. 이를 state 끌어올리기라고 한다.

예제 흐름
1. 부모가 메뉴 목록 state와 handleAddMenu 함수를 소유한다.
2. 부모가 <MenuForm onAdd={handleAddMenu} />로 함수를 자식에게 전달한다.
3. 자식은 입력값을 관리하고 제출할 때 onAdd(메뉴 이름)을 호출한다.
4. 부모 callback이 목록 state를 갱신하면 React가 메뉴 목록을 다시 렌더링한다.
5. 메뉴 항목 자식도 즐겨찾기 전환과 삭제 callback을 부모에게 요청한다.

복습
- 자식이 부모 state를 직접 수정하지 않는 이유와 callback prop의 역할을 설명한다.
- 실제 앱에서는 폼의 onSave, 목록의 onRefresh처럼 자식 동작을 부모 로직에 연결하는 데 활용한다.
