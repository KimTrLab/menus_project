강의 필기: 단방향 데이터 흐름과 Callback Props

핵심 개념
- Props 데이터는 부모에서 자식 방향으로 전달된다.
- 자식은 부모의 state를 직접 수정하지 않는다.
- 자식에게 부모가 만든 함수를 prop으로 전달하고, 자식은 그 함수를 호출해 변경을 요청한다. 이런 함수를 callback prop이라고 한다.

왜 state를 부모로 올릴까?
- 메뉴 등록 폼과 메뉴 목록이 같은 메뉴 배열을 사용한다.
- 배열을 두 컴포넌트가 각각 소유하면 서로 다른 값이 되어 화면이 어긋날 수 있다.
- 두 컴포넌트의 가장 가까운 공통 부모가 state를 소유하면 한 곳의 변경을 양쪽 화면이 공유한다. 이를 state 끌어올리기라고 한다.

예제의 데이터 흐름
1. 부모는 메뉴 배열과 추가·즐겨찾기·삭제 함수를 소유한다.
2. 부모는 MenuForm에 onAdd 함수를 props로 전달한다.
3. MenuForm은 입력값을 관리하고 제출 시 onAdd(메뉴 이름)을 호출한다.
4. 부모가 callback을 받아 메뉴 배열을 새 값으로 갱신한다.
5. 새 props가 목록 자식에게 전달되고, React가 새 메뉴 화면을 렌더링한다.

요청과 응답의 방향
- 데이터와 표시용 props는 부모에서 자식으로 흐른다.
- 사용자 동작은 자식의 callback 호출을 통해 부모에게 전달된다.
- 실제 state 변경 권한은 state를 소유한 부모에 남아 있어 데이터 흐름을 추적하기 쉽다.
