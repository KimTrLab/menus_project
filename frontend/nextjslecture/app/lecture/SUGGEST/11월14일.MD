# 실무 흐름으로 다시 구성한 React 강의 제안

## 강의 방향

수강생이 JavaScript를 할 수 있으므로 함수, 배열 메서드, 객체, 이벤트, Promise를 별도 선수 단원으로 길게 가르치지 않습니다. 필요한 문법은 React 실습 중 다시 짚고, 처음부터 작은 메뉴 관리 화면을 만들며 React 개념과 조립을 함께 익히는 방식으로 진행합니다.

함수 컴포넌트, JSX, `useState`처럼 실제 화면에서 늘 함께 쓰이는 개념은 따로 떼어 가르치지 않습니다. 개념을 짧게 설명한 직후 실제 동작을 만들고, 다음 단계에서 그 코드를 컴포넌트와 데이터 흐름으로 확장합니다.

## 추천 강의 순서

### 1. 화면을 움직이기: 함수 컴포넌트 + JSX + `useState` + 이벤트

- 활용 자료: `001_useState`, `002_useState_01`
- 함수 컴포넌트와 JSX를 설명하면서 `useState`를 함께 소개합니다.
- 버튼 클릭과 입력 이벤트를 연결해 상태가 바뀌면 화면이 다시 그려지는 것을 바로 확인합니다.
- **실습 결과:** 메뉴 이름을 입력하고, 메뉴 수나 선택 상태가 화면에 반영되는 작은 화면
- `001_useState`와 `002_useState_01`은 별도 이론 강의 두 개로 나누기보다 한 흐름의 예제와 응용으로 사용합니다.

### 2. 데이터로 화면 만들기: 배열 렌더링 + `map` + `key` + Props + 컴포넌트 합성

- 활용 자료: `003_list`, `004_props`, `005_children_composition`
- 메뉴 객체 배열을 JSX 목록으로 렌더링한 다음, 각 메뉴 표시를 `MenuCard` 같은 함수 컴포넌트로 분리합니다.
- 부모에서 자식으로 Props를 전달하고, 반복되는 외곽 UI는 `children`으로 조합합니다.
- **실습 결과:** 메뉴 목록과 재사용 가능한 메뉴 카드
- `006_map_optional`의 JavaScript `Map` 자료형은 배열의 `map()`과 혼동될 수 있으므로 필수 순서에서 빼고 선택 확장으로 둡니다. 일반적인 목록 렌더링에는 배열과 `map()`을 사용합니다.

### 3. 실제 상호작용 붙이기: 폼 + 이벤트 + 불변 업데이트 + Callback Props + 조건부 렌더링

- 활용 자료: `007_form_events`, `008_immutable_state`, `009_callback_props`, `010_conditional_rendering`
- 폼 입력값을 상태로 관리하고 제출하면 부모 컴포넌트의 메뉴 목록에 추가합니다.
- 자식 폼은 Callback Props로 부모에게 변경을 요청하고, 부모는 함수형 상태 갱신과 불변 업데이트로 목록을 추가·수정·삭제합니다.
- 입력 전후의 빈 목록, 유효하지 않은 입력, 등록 후 화면도 조건부 렌더링으로 함께 다룹니다.
- **실습 결과:** 메뉴를 등록하고, 완료/즐겨찾기 상태를 바꾸고, 삭제할 수 있는 화면
- 이 단계에서 Props를 다시 사용해 단방향 데이터 흐름과 상태를 어디에 둘지 자연스럽게 익힙니다.

### 4. 서버 데이터를 다루기: `useEffect` + 비동기 요청 + 로딩·오류·빈 상태

- 활용 자료: `011_useEffect`, `012_async_data`, `010_conditional_rendering`
- “언제 실행되는가”를 외우는 데 그치지 않고, 화면에 필요한 데이터를 불러오는 실제 상황에서 Effect와 `async/await`를 연결합니다.
- 요청 중, 성공, 실패, 결과 없음 상태를 나누어 사용자에게 맞는 화면을 보여줍니다.
- 의존성 배열과 정리(cleanup)는 재요청이나 컴포넌트 종료 시 어떤 문제가 생기는지 예제와 함께 다룹니다.
- **실습 결과:** 로딩 및 오류 안내가 있는 메뉴 목록 화면

### 5. 화면을 URL로 나누기: Next.js 라우팅 + 동적 경로 + 상세 화면

- 활용 자료: `013_router`, `014_router2`
- 먼저 만든 메뉴 목록을 목록 페이지와 상세 페이지로 나누고, URL의 경로 매개변수로 해당 메뉴를 표시합니다.
- 라우팅을 React 기초보다 먼저 다루지 않고, 컴포넌트와 데이터 흐름이 익숙해진 뒤 실제 앱 구조를 확장하는 단계로 배치합니다.
- **실습 결과:** 메뉴 목록에서 메뉴 상세 페이지로 이동하는 작은 앱

## 한 강의 블록의 진행 방식

1. 이번 실습에서 만들 사용자 기능을 먼저 보여 줍니다.
2. 기능을 구현하는 데 필요한 React 개념을 그 자리에서 짧게 설명합니다.
3. 강사와 함께 코드를 조립해 동작을 확인합니다.
4. 입력값, 데이터 또는 화면 상태를 바꿔 학생이 같은 개념을 응용하게 합니다.

즉, 개념을 전부 설명한 뒤 마지막에 조립하는 방식이 아니라 **기능을 만들면서 개념을 배우고, 배운 개념을 바로 조립해 결과를 확인하는 방식**입니다. 각 순서는 독립된 문법 단원이 아니라 하나의 메뉴 관리 화면을 점차 실무 형태로 키우는 단계입니다.
