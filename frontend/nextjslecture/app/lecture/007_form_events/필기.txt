강의 필기: 폼 이벤트로 메뉴 등록하기

핵심 내용
- controlled form은 input의 value를 React state에 연결하고 onChange에서 state를 갱신한다.
- 폼의 onSubmit은 제출 이벤트를 처리한다. event.preventDefault()를 호출하면 브라우저의 기본 페이지 새로고침을 막을 수 있다.
- input의 name으로 어떤 필드가 바뀌었는지 확인하고, 함수형 state 갱신으로 해당 입력값만 바꾼다.
- 제출한 메뉴를 기존 배열에 추가해 화면 목록을 갱신한다.

코드에서 볼 점
- 숫자 input도 event.target.value로 읽은 값은 문자열이다. 숫자로 사용할 때 Number()로 변환한다.
- required, min 같은 HTML 속성으로 기본 입력 검증을 적용한다.
- submit 버튼은 폼을 제출하고, type="button"인 초기화 버튼은 폼 제출을 발생시키지 않는다.
- 메뉴 배열은 기존 값을 직접 수정하지 않고 새 배열을 만들어 갱신한다.

실제 앱과 연결
- 이 예제는 폼과 목록을 한 컴포넌트에서 다룬다.
- 다음 단계에서는 폼을 자식 컴포넌트로 분리하고 callback prop으로 부모 목록을 갱신한다.

기능개선
- 이름을 공백으로만 입력하면 등록하지 않고 오류 메시지를 보여 준다.
- 입력을 다시 시작하면 이전 오류 메시지를 지운다.
