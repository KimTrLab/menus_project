강의 필기: 여러 종류의 useState 상태

핵심 내용
- count는 숫자, isOn은 불리언, text는 문자열 상태의 예다.
- 각 useState 호출은 서로 독립된 상태와 갱신 함수를 만든다.
- 상태를 사용하는 JSX는 값이 바뀔 때 다시 렌더링되어 현재 상태를 보여 준다.

코드에서 볼 점
- 숫자: setCount(count + 1)로 카운트를 증가시킨다.
- 불리언: setIsOn(!isOn)으로 켜짐/꺼짐 상태를 반전한다.
- 문자열: input의 value를 text에 연결하고 onChange에서 setText(e.target.value)를 호출한다.
- value와 onChange를 연결한 입력창은 controlled input이다. 입력값의 기준은 React state다.
- 'use client'는 Hook과 브라우저 입력 이벤트를 쓰는 컴포넌트에 필요하다.

복습
- 상태의 초기값과 값의 타입에 맞는 setter 사용법을 확인한다.
- state를 직접 변경하지 말고 해당 setter로 새 값을 전달한다.
