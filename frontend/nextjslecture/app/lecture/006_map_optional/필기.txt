선택 강의 필기: JavaScript Map과 배열의 map()

먼저 구분하기
- Map은 키와 값의 쌍을 저장하는 JavaScript 자료구조다.
- 배열의 map()은 배열의 각 요소를 다른 값으로 바꾸어 새 배열을 만드는 메서드다.
- 이름은 비슷하지만 하나는 자료구조(Map), 다른 하나는 배열 메서드(map())다.

Map의 동작 원리
1. 메뉴 이름을 key, 가격을 value로 연결해 저장한다.
2. entries()는 Map 안의 항목을 [key, value] 쌍으로 순회할 수 있게 한다.
3. Array.from()으로 그 항목들을 배열로 만든다.
4. 배열의 map()으로 각 쌍을 JSX 목록 요소로 바꾼다.

이 예제에서 중요한 점
- React 화면은 배열의 map()으로 만든 JSX 요소 목록을 렌더링한다.
- Map 자체를 배열 map()과 같은 것으로 취급하면 안 된다.
- 일반적인 React 목록에서는 id, name, price 같은 속성을 가진 객체 배열이 이해하기 쉽다.

선택 학습인 이유
- Map은 키 기반 조회가 필요할 때 유용하지만, 기본 목록 렌더링을 시작하는 데 필수는 아니다.
- 먼저 배열, 객체, 배열의 map()으로 화면을 만들고 필요할 때 Map 자료구조를 배운다.
