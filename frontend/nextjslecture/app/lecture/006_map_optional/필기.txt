선택 강의 필기: JavaScript Map 렌더링

핵심 내용
- Map은 키와 값의 쌍을 저장하는 자료형이다. 이 예제에서는 메뉴 이름을 키, 가격을 값으로 사용한다.
- Map은 배열의 map() 메서드와 다른 자료형이다.
- entries()는 Map의 키와 값을 [key, value] 형태로 순회할 수 있게 한다.
- Array.from(menuPrices.entries())로 항목을 배열로 만든 뒤 배열의 map()을 적용해 JSX 목록을 렌더링한다.

코드에서 볼 점
- ([name, price]) 구조 분해로 각 항목의 키와 값을 얻는다.
- <li>의 key에는 목록 안에서 고유한 메뉴 이름을 전달한다.
- Map을 화면에 표시하려면 렌더링 가능한 배열 형태로 변환한다.

복습
- 일반 목록 렌더링에서는 객체 배열과 배열의 map()을 먼저 사용하고, JavaScript Map은 필요할 때 확장 주제로 다룬다.
- Map 자료형과 배열의 map() 메서드가 서로 다른 개념임을 설명해 본다.
