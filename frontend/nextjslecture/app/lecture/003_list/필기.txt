강의 필기: 데이터 배열에서 UI 목록 만들기

핵심 개념
- 배열은 순서가 있는 여러 데이터를 하나의 값으로 관리한다.
- 메뉴 객체는 한 메뉴의 이름, 분류, 가격처럼 함께 다뤄야 하는 속성을 묶는다.
- map()은 원본 배열의 각 값을 받아 새 배열을 만든다. 여기서는 메뉴 객체 하나를 화면 요소 하나로 변환한다.

React는 목록을 어떻게 처리할까?
1. menus 배열을 map()으로 순회해 메뉴마다 React 요소를 만든다.
2. 컴포넌트는 그 요소 배열을 JSX 결과에 포함해 반환한다.
3. React는 이전 렌더의 목록과 새 목록을 비교해 항목의 추가, 삭제, 변경을 파악한다.
4. key를 이용해 항목이 이전 렌더의 어느 항목과 같은지 판단하고 필요한 부분을 갱신한다.

key가 필요한 이유
- key는 같은 목록 안에서 각 항목을 구별하는 식별자다.
- 데이터의 고유한 id를 key로 쓰면 항목 순서가 바뀌거나 삭제되어도 React가 항목의 정체성을 추적할 수 있다.
- 배열의 index는 앞 항목이 삭제될 때 뒤 항목의 위치가 달라질 수 있어, 변경 가능한 목록에서는 적절한 식별자가 아니다.
- key는 React가 목록을 비교할 때 사용하는 값이며, 자식 컴포넌트의 일반 props로 전달되는 값은 아니다.

생각해 보기
- 메뉴 배열에 새 데이터가 추가되면 map()이 어떤 화면 요소를 더 만들까?
- 메뉴의 이름은 같지만 id가 다른 두 항목은 왜 서로 다른 key를 가져야 할까?
