강의 필기: useEffect와 외부 시스템 동기화

핵심 개념
- React 렌더링은 state와 props로 화면을 계산한다.
- 브라우저 탭 제목(document.title)처럼 React 바깥에서 관리되는 값은 화면 렌더링만으로 바뀌지 않는다.
- useEffect는 렌더링이 반영된 뒤 외부 시스템을 React state와 동기화할 때 사용한다.

Effect가 실행되는 흐름
1. 즐겨찾기 버튼이 state를 변경하도록 요청한다.
2. React가 새 state로 컴포넌트를 실행하고 화면 변경을 반영한다.
3. 렌더가 끝난 뒤 Effect가 실행되어 document.title을 새 즐겨찾기 수와 맞춘다.
4. 의존성 배열의 favoriteCount가 바뀌면 Effect가 다시 실행된다.

이벤트와 Effect의 역할 구분
- 버튼을 눌렀을 때 할 일은 이벤트 핸들러에 둔다.
- state가 바뀐 뒤 브라우저 제목처럼 React 밖의 대상을 맞추는 일은 Effect에 둔다.
- 렌더링 함수 안에서 document.title을 직접 바꾸면 렌더 계산에 외부 변경이 섞인다. Effect로 분리하면 역할이 분명해진다.

이 예제에서의 경계
- useEffect와 document는 브라우저에서만 쓸 수 있으므로 이 페이지는 Client Component다.
- 이 Effect는 외부 값을 설정하지만 구독이나 타이머를 만들지 않으므로 별도 cleanup은 필요하지 않다.
- 다음 비동기 데이터 강의에서는 요청이 끝나기 전 컴포넌트 상황이 바뀌는 문제와 cleanup을 다룬다.
