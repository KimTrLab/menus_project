강의 필기: JavaScript Map 렌더링

핵심 내용
- Map은 키와 값의 쌍을 저장하는 자료형이다. 이 예제에서는 학생 이름을 키, 점수를 값으로 사용한다.
- entries()는 Map의 키와 값을 [key, value] 형태로 순회할 수 있게 한다.
- Array.from(studentScores.entries())로 항목을 배열로 만든 뒤 map()을 적용해 JSX 목록을 렌더링한다.

코드에서 볼 점
- ([name, score]) 구조 분해로 각 항목의 키와 값을 얻는다.
- <li>의 key에는 목록 안에서 고유한 학생 이름을 전달한다.
- Map의 데이터를 React 화면에 표시할 때는 화면에 필요한 배열 형태로 변환해 렌더링할 수 있다.

복습
- 객체 배열과 Map의 데이터 모양 및 접근 방법을 비교한다.
- Map은 다양한 타입의 키와 삽입 순서를 활용할 수 있고, 배열은 순서 있는 항목 목록 처리에 편리하다.
