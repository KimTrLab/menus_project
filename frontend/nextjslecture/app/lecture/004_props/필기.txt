강의 필기: Props와 컴포넌트 사이의 데이터 전달

핵심 개념
- Props는 부모 컴포넌트가 자식 컴포넌트에 전달하는 입력값이다.
- 자식은 같은 컴포넌트 구조를 서로 다른 데이터로 재사용할 수 있다.
- Props는 전달받아 읽는 값이다. 자식이 props를 직접 바꾸는 대신, 변경이 필요하면 부모에게 요청한다.

예제의 데이터 흐름
1. 부모가 메뉴 객체 배열을 소유한다.
2. 부모가 map()으로 배열을 순회해 메뉴마다 MenuCard를 만든다.
3. 각 메뉴의 name, category, price가 MenuCard의 props가 된다.
4. MenuCard는 전달받은 값으로 메뉴 한 개의 UI를 반환한다.

컴포넌트 분리의 의미
- 부모는 데이터와 목록 반복을 담당한다.
- 자식 MenuCard는 메뉴 하나를 어떤 구조로 보여 줄지 담당한다.
- 책임을 나누면 같은 카드 UI를 다른 목록이나 화면에서도 재사용하기 쉽다.
- 부모의 데이터가 바뀌면 새 props가 전달되고, React는 그 값으로 자식의 화면을 다시 계산한다.

key와 props의 차이
- key는 React가 배열 항목의 정체성을 추적할 때 사용한다.
- key는 일반 props가 아니므로 MenuCard 안에서 읽지 않는다.
- name, category, price처럼 자식이 화면에 필요한 값은 별도의 props로 전달한다.

생각해 보기
- 메뉴 데이터를 MenuCard 내부에 직접 적는 대신 부모가 전달하면 어떤 점이 좋아질까?
- 메뉴 이름이 바뀌면 부모와 자식 중 어느 쪽이 데이터를 바꿔야 할까?
