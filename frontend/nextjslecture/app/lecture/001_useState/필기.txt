강의 필기: useState로 카운터 만들기

핵심 내용
- useState는 컴포넌트가 기억할 상태를 선언하는 React Hook이다.
- useState(0)의 반환값을 배열 구조 분해로 count와 setCount에 나눈다.
- count는 현재 값이고, setCount는 다음 상태를 요청하는 함수다.
- 상태가 변경되면 React가 컴포넌트를 다시 렌더링해 화면의 count도 갱신한다.

코드에서 볼 점
- +1 버튼은 setCount(count + 1)로 값을 증가시킨다.
- 초기화 버튼은 setCount(0)으로 상태를 초기값으로 되돌린다.
- 이 파일은 useState와 클릭 이벤트를 사용하므로 클라이언트 컴포넌트임을 나타내는 'use client'가 필요하다.

복습
- 일반 변수와 state가 다른 점은 state 변경이 화면 갱신을 유발한다는 것이다.
- 이전 상태를 기준으로 여러 번 갱신할 때는 setCount(current => current + 1)처럼 함수형 업데이트를 고려한다.
