강의 필기: 메뉴 즐겨찾기와 useState

핵심 내용
- 함수 컴포넌트는 JSX를 반환해 화면을 구성한다.
- useState(false)는 컴포넌트가 기억할 즐겨찾기 상태와 갱신 함수를 만든다.
- 버튼 클릭으로 상태를 바꾸면 React가 다시 렌더링하고, JSX가 새 상태를 표시한다.

코드에서 볼 점
- isFavorite은 현재 상태이고 setIsFavorite은 다음 상태를 요청한다.
- onClick에 함수를 전달해 사용자의 버튼 클릭과 상태 갱신을 연결한다.
- 이전 상태를 기준으로 갱신하므로 setIsFavorite(current => !current) 형태를 사용한다.
- Hook과 브라우저 이벤트를 사용하므로 'use client'가 필요하다.

복습
- 일반 변수와 state가 다른 점은 state 변경이 화면 갱신을 유발한다는 것이다.
- 함수 컴포넌트, JSX, state, 이벤트가 한 기능 안에서 어떻게 연결되는지 설명해 본다.
