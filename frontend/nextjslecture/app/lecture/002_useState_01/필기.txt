강의 필기: 입력 state와 controlled input

핵심 개념
- 브라우저의 input 요소에는 사용자가 입력한 값이 있다.
- controlled input에서는 React state가 입력창에 표시되는 값의 기준이 된다.
- onChange 이벤트가 발생하면 입력값을 state에 저장하고, React가 새 값으로 화면을 렌더링한다.

이 예제의 단계
1. name state는 처음에 빈 문자열이다.
2. 사용자가 글자를 입력하면 onChange에서 event.target.value를 읽는다.
3. setName으로 새 값을 React에 요청한다.
4. React가 컴포넌트를 다시 실행하고, value와 미리보기에 새 name을 넣는다.

배운 내용을 메뉴 기능으로 확장하기
- #1 미리보기: 입력 state를 JSX에 표시한다.
- #2 배열에 추가: 현재 메뉴 배열을 복사하고 새 이름을 붙여 새 배열을 state로 저장한다.
- #3 추가와 삭제: 메뉴를 { id, name } 객체로 저장하고, 삭제할 때 filter()로 새 배열을 만든다.
- 각 항목의 id는 메뉴를 구별하는 식별자다. 배열의 위치와 달리 삭제 뒤에도 같은 메뉴를 식별할 수 있다.

React의 데이터 흐름
- state가 입력값의 기준이므로 화면과 데이터가 같은 값을 바라본다. 이를 단방향 데이터 흐름의 일부로 볼 수 있다.
- state setter는 값을 즉시 변수에 대입하는 대신 React에 변경을 요청한다.
- 이 페이지는 input 이벤트를 처리하므로 Next.js에서 'use client'가 필요하다.

생각해 보기
- 일반 변수에 입력값을 저장하는 것과 state에 저장하는 것은 화면 갱신에서 어떻게 다를까?
- 메뉴 목록에 항목을 추가할 때 기존 배열을 직접 바꾸지 않고 새 배열을 만드는 이유는 무엇일까?
