강의 필기: Next.js App Router

핵심 내용
- App Router는 app 디렉터리의 폴더와 page.js 파일을 조합해 URL 경로를 만든다.
- 이 실습의 시작 경로는 /lecture/004_router다.
- about/page.js는 /lecture/004_router/about, posts/page.js는 /lecture/004_router/posts 경로에 해당한다.

화면 이동
- next/link의 Link 컴포넌트로 내부 경로를 연결한다.
- 게시글 목록은 posts 배열을 map()으로 렌더링하고 각 게시글 상세 링크를 만든다.
- 목록과 소개 페이지에서 실습 시작 페이지로 돌아가는 링크도 제공한다.

동적 경로
- posts/[id]/page.js에서 대괄호로 감싼 id는 URL에 따라 달라지는 동적 세그먼트다.
- 예: /lecture/004_router/posts/1의 id 값은 "1"이다.
- Next.js 16에서는 page의 params가 Promise이므로 async 페이지에서 await params로 값을 얻는다.
- 전달된 id를 게시글 데이터와 비교하고, 일치하는 항목이 없으면 next/navigation의 notFound()로 404 처리를 한다.

복습
- 디렉터리 구조로 정적 경로와 동적 경로를 구분해 본다.
- URL, Link의 href, 동적 세그먼트 params가 어떻게 이어지는지 추적한다.
